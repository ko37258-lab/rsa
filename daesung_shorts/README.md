# 대성 부동산 입지 분석 — 1분 9:16 모션그래픽

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 9:16(1080×1920) 모션그래픽 템플릿. 브라우저로 열고 ▶ 재생. `frame(t)` 함수로 프레임 단위 렌더 가능 |
| `대성_입지분석_쇼츠_9x16.mp4` | 렌더 결과 (60초, 배경음악·효과음 포함, **내레이션 없음**) |

## 수정된 내레이션
1. 빅뱅 대성이 14억에 사서 100억이 됐다는 흑석동 아파트, 단순히 운이 좋아서 올랐을까요?
2. 대성이 2015년에 산 곳은 흑석동 마크힐스입니다. 당시 14억 5천만 원이었던 이 집, 지금은 시세가 약 100억 원 수준으로 알려져 있죠.
3. 11년 만에 약 7배. 비결은 독보적인 한강 조망권과 18세대뿐인 소수 정예 단지의 보안입니다. 장동건·고소영 부부, 현빈, 그리고 지금은 김연아·고우림 부부까지, 톱스타들이 선택한 이유가 있죠.
4. 대성은 2017년 논현동 빌딩도 310억 원에 매입했습니다. 지금은 시세가 900억 원대로 추정되죠. 철저히 희소성 높은 입지만 골라낸 결과입니다.
5. 부자들의 투자 공식은 결국 대체 불가능한 입지입니다. 더 많은 연예인 부동산 입지 분석이 궁금하다면 구독과 좋아요를 눌러주세요!
