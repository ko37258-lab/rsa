# silly-nash-a47743 — 이미지 + 모션 리디자인

`https://silly-nash-a47743.vercel.app/` 에 덮어쓸 **변경 파일만** 모아 둔 폴더입니다.
로컬 `silly-nash-local` 폴더에 같은 경로로 복사한 뒤 평소처럼 `vercel --prod` 로 배포하면 됩니다.

## 바뀐 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 홈 전체 재구성 (히어로 항공사진, 마키 띠, 인트로 사진, 단계 카드 이미지, 시뮬레이터 이미지 카드, 도시 야경 CTA) |
| `css/home-motion.css` | 홈 전용 스타일 (새 파일) |
| `css/motion.css` | 전 페이지 공통 모션 스타일 (새 파일) |
| `js/motion.js` | 전 페이지 공통 모션 엔진 (새 파일) |
| `js/theme-switcher.js` | 맨 아래에 `motion.css` / `motion.js` 자동 로드 추가 → 서브페이지 HTML은 수정 없이 모션 적용 |
| `assets/hx-*.webp` | Higgsfield(GPT Image 2.5)로 생성한 이미지 13장 |

## 마우스·스크롤 반응

- **홈 히어로**: 사진 속 실제 빈 필지 위에 대지경계·계단형 건축 매스(일조 사선)를 겹쳤습니다. 마우스를 좌우로 움직이면 해가 궤적을 따라 이동하고 건물 그림자와 벽면 밝기가 바뀝니다. 터치 기기에서는 해가 자동으로 움직입니다.
- **커서 링**: 링크·카드 위에서 커지고, 카드 위에서는 `열기 / 실행 / 보기` 라벨이 뜹니다. 입력칸·지도·캔버스 위에서는 숨습니다.
- **카드**: 3D 틸트 + 커서를 따라가는 금색 테두리 빛 + 이미지가 커서 반대쪽으로 패닝.
- **버튼**: 커서 쪽으로 살짝 끌려오는 마그네틱 효과.
- **스크롤**: 제목 줄 단위 등장, 카드 순차 등장, 숫자 카운트업, LAND/MASS/COST 스크램블, 인용문 단어별 점등, 단계 진행선, 스크롤 속도에 반응하는 키워드 마키, 상단 진행바.
- **마스터 비주얼(SVG)**: 마우스 위치에 따라 단계 카드·건물·결과 카드가 서로 다른 깊이로 떠오르고, 단계 카드가 순서대로 점등, 창문 불빛, 화살표 흐름.
- **서브페이지**: 토지 분석·건축 시뮬레이션·비용·보고서 페이지 히어로 오른쪽에 단계별 생성 이미지가 패럴랙스로 들어갑니다.

## 안전장치

- `prefers-reduced-motion` 설정 시 모든 움직임을 끄고 내용은 그대로 보여줍니다.
- 인쇄(PDF 보고서 출력) 시 커서·진행바·히어로 아트를 모두 숨깁니다.
- `motion.js`가 4초 안에 로드되지 않으면 숨김 처리 없이 원래 내용이 보입니다.
- 색은 모두 테마 변수(`--orange`, `--light`)를 따르므로 좌하단 테마 스킨을 바꿔도 어울립니다.
