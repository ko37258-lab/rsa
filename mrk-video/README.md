# MR.K 영상만들기

사진과 대본으로 쇼츠 영상을 만들고, 상품·매물 대표 이미지를 한꺼번에 합성·다운로드하는 웹 도구입니다.
설치 없이 브라우저(크롬·엣지 권장)에서 바로 쓰고, Vercel에 올리면 어디서든 인터넷 주소로 접속할 수 있습니다.

> 이 프로젝트는 "메이커 셀링 도우미"(sellergram) 설치 파일을 분석한 결과를 바탕으로, **공개된 기능 설명만 참고해 새로 작성한** 웹 버전입니다. 분석 내용은 [docs/ANALYSIS.md](docs/ANALYSIS.md)에 있습니다.

## 기능

### 01 숏폼 영상 만들기
- 사진 여러 장을 넣으면 순서대로 장면이 됩니다. 사진 없는 "글자 장면"도 넣을 수 있습니다(강의 요점 정리용).
- 대본을 한 줄에 한 장면씩 붙여 넣으면 자막이 들어갑니다. `*강조*`로 감싼 단어는 노란 글씨가 됩니다.
- 화면 비율 9:16 / 1:1 / 16:9, 레이아웃 3종(위 제목·가운데 사진 / 흐린 배경 / 꽉 채우기), 한글 글꼴 6종.
- 사진 움직임(확대·축소·좌우 이동), 장면 전환(겹치기·밀기·확대), 진행 막대, 채널 이름·로고, 엔딩 화면.
- 배경음악·내레이션 넣기, "장면 길이를 내레이션에 맞추기"(자막 글자 수 비율로 자동 배분).
- MP4(크롬·엣지) 또는 WEBM으로 저장, 자막 SRT 복사·저장, 프로젝트(.json) 저장·열기.
- **AI 대본 만들기**: 주제·유형(공법 강의, 부동산 이슈, 매물 소개, 토지 투자 등)·장면 수를 넣으면 Claude가 자막·제목·유튜브 설명·해시태그를 씁니다.

### 02 대표 이미지 합성
- 메인 사진 여러 장 + 서브 사진(구성품·라벨·로고)을 정사각형 캔버스에 같은 자리로 일괄 합성.
- 미리보기에서 서브 사진을 끌어서 위치 조정, 크기·테두리·모서리·그림자, "1+1 특가" 같은 문구 뱃지.
- JPG/PNG/WEBP, 파일 이름 규칙(`{name}`, `{n}`), ZIP 또는 PC 폴더로 저장.

### 03 이미지 일괄 다운로드
- 엑셀에서 상품 코드·이미지 주소를 복사해 표에 붙여 넣기(여러 줄·두 칸 동시 지원).
- 파일 이름 바꾸기(`앞글자_상품코드_뒷글자`), 크기 맞추기(300~1500px), 압축 4단계, 요청 간격 3단계.
- PC에 있는 사진도 같은 규칙으로 일괄 변환.
- 사이트가 직접 받기를 막으면 서버 프록시(`api/proxy.js`)가 대신 받습니다(Vercel 배포 시).

## 바로 써 보기 (내 PC)

```bash
cd mrk-video
python3 -m http.server 5173
# 브라우저에서 http://localhost:5173 열기
```

이렇게 열면 영상 만들기·합성·PC 사진 변환은 모두 동작합니다. AI 대본과 서버 프록시는 아래 Vercel 배포(또는 `npx vercel dev`)에서 켜집니다.

## 인터넷에 올리기 (Vercel, 무료 요금제로 충분)

1. https://vercel.com 에 GitHub 계정으로 로그인 → **Add New… › Project** → 이 저장소(`rsa`) 선택
2. **Root Directory**를 `mrk-video`로 지정 (Framework Preset은 `Other`)
3. **Environment Variables**에 아래 두 값을 넣고 **Deploy**

| 이름 | 값 | 용도 |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com에서 발급한 키 | AI 대본 |
| `ACCESS_CODE` | 내가 정한 비밀 문구 | 남이 내 키·서버를 쓰지 못하게 막음 |

배포가 끝나면 `https://<프로젝트이름>.vercel.app` 주소가 생깁니다. 처음 접속하면 **사용 안내** 탭에서 접속 코드를 한 번 입력하세요(그 브라우저에 기억됩니다).
`ACCESS_CODE`를 넣지 않으면 AI 기능은 꺼진 채로 동작합니다.

GitHub에 새 커밋을 올리면 Vercel이 자동으로 다시 배포합니다.

## 폴더 구조 — 어디를 고치면 무엇이 바뀌나

```
mrk-video/
├─ index.html            화면 뼈대(메뉴·입력 칸·버튼). 문구를 바꾸려면 여기
├─ css/style.css         색·글꼴·배치. 맨 위 :root의 색 변수만 바꿔도 분위기가 바뀝니다
├─ js/
│  ├─ main.js            메뉴 전환, 사용 안내의 환경 표시
│  ├─ shorts.js          숏폼 화면: 장면 목록, 미리보기 재생, 소리, 영상 내보내기
│  ├─ shorts-render.js   영상 한 프레임을 그리는 코드(제목·자막·전환·엔딩) ← 영상 모양은 여기
│  ├─ script-prompt.js   AI 대본 프롬프트와 결과 형식 ← AI 말투·규칙은 여기
│  ├─ compose.js         대표 이미지 합성
│  ├─ downloader.js      이미지 일괄 다운로드
│  ├─ platform.js        파일 저장·AI 호출을 환경(Claude 아티팩트/웹)에 맞게 처리
│  └─ util.js            공용 도구, 예시 그림
├─ api/                  Vercel 서버 함수
│  ├─ ai.js              AI 대본 (Claude API)
│  ├─ proxy.js           이미지 프록시 (내부망 차단·이미지만·20MB 제한)
│  └─ health.js          서버 기능 켜짐 여부
├─ scripts/artifact-page.mjs   Claude 아티팩트용 페이지 만들기
└─ docs/ANALYSIS.md      설치 파일 분석 보고서
```

빌드 도구가 없는 순수 HTML·CSS·JavaScript라서, 파일을 고치고 새로고침하면 바로 반영됩니다.

## 바이브 코딩으로 키워 가기

Claude Code에서 이 폴더를 열고 하고 싶은 것을 말하면 됩니다. 예:

- "숏폼 레이아웃에 '뉴스 속보' 스타일 추가해줘. 위에 빨간 띠, 아래 자막은 흰 박스"
- "AI 대본 유형에 '경매 물건 분석'을 추가해줘"
- "합성 화면에 워터마크 글자(대각선 반복) 옵션 넣어줘"
- "영상에 장면마다 다른 배경음악 구간을 넣을 수 있게 해줘"
- "내레이션 녹음을 브라우저에서 바로 할 수 있게 해줘"

규칙과 구조 설명은 [CLAUDE.md](CLAUDE.md)에 있어 Claude가 자동으로 참고합니다.

## 알아 둘 점

- 영상은 실제 길이만큼 녹화하듯 만듭니다(30초 영상 ≈ 30초). 만드는 동안 탭을 띄워 두세요.
- 사진·소리는 서버로 올라가지 않습니다. 서버로 가는 것은 AI 대본 요청(주제 글)과 프록시로 받는 이미지 주소뿐입니다.
- AI가 쓴 법령·수치는 올리기 전에 꼭 확인하세요.
