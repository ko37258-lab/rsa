# MR.K 영상만들기

사진과 대본으로 쇼츠 영상을 만들고, 상품·매물 대표 이미지를 한꺼번에 합성·다운로드하는 웹 도구입니다.
설치 없이 브라우저(크롬·엣지 권장)에서 바로 쓰고, Vercel에 올리면 어디서든 인터넷 주소로 접속할 수 있습니다.

> 이 프로젝트는 "메이커 셀링 도우미"(sellergram) 설치 파일을 분석한 결과를 바탕으로, **공개된 기능 설명만 참고해 새로 작성한** 웹 버전입니다. 분석 내용은 [docs/ANALYSIS.md](docs/ANALYSIS.md)에 있습니다.

## 기능

### 00 사례 보기
- 실제 렌더 엔진이 돌아가는 살아 있는 미리보기로 "넣는 것 → 나오는 것"을 보여 줍니다(토지 쇼츠, 30가지 스타일, 대표 이미지 합성·일괄 다운로드).
- 예시 사진은 힉스필드(gpt_image_2_5)로 만든 실사 이미지(`assets/samples/`)입니다.

### 01 숏폼 영상 만들기
- **잘 나가는 쇼츠 스타일 30가지**(`js/styles-data.js`): 강의형·속보형·TOP3·오해vs진실·체크리스트·퀴즈·밈 자막… 스타일을 누르면 같은 장면이 그 형식으로 바뀝니다. 스타일마다 "이 형식의 잘 나가는 영상 보기" 링크가 있습니다.
- **30가지 전부 만들기**(버튼·안내 문구의 숫자는 스타일 수를 따라 자동으로 바뀜): 같은 내용을 30가지 스타일로 차례로 만들어 하나씩 저장하거나 ZIP(영상 + 업로드용 글 + 자막)으로 한 번에 저장합니다.
- **빵터진 영상 찾기**: 주제를 넣으면 유튜브에서 최근 1년 조회수 높은 쇼츠를 보여 주고(서버에 `YOUTUBE_API_KEY`가 있을 때), 영상을 누르면 그 컨셉으로 AI 대본을 씁니다. 키가 없으면 유튜브 검색 링크로 대신합니다.
- **바로 올리기**: 영상이 완성되면 유튜브 쇼츠·인스타 릴스·틱톡·페이스북 릴스·쓰레드 규격(비율·길이·용량)을 확인해 주고, 업로드 화면 링크와 제목·설명·해시태그 복사 버튼을 보여 줍니다.
- 사진 여러 장을 넣으면 순서대로 장면이 됩니다. 사진 없는 "글자 장면"도 넣을 수 있습니다. 장면마다 종류(훅·보통·정답·마무리)와 태그(가격·날짜)를 줄 수 있습니다.
- 대본을 한 줄에 한 장면씩 붙여 넣으면 자막이 들어갑니다. `*강조*`로 감싼 단어는 강조색이 됩니다.
- 화면 비율 9:16 / 1:1 / 16:9, 레이아웃 6종(위 제목·흐린 배경·꽉 채우기·위 사진 아래 글·사진 카드·글자 중심), 자막 등장 10종(한 번에·단어씩·가라오케·타자기·틱톡식 팝·튕기며 떨어지기·커지며 등장·옆에서 밀려오기·물결·깜빡 강조), 자막 모양 12종(테두리·검은 띠·글씨만·강조색 알약·네온 빛·3D 그림자·형광펜·유리 패널·단어 칩·밑줄·그라데이션·말풍선), 장식 16종(속보 띠·경고 테이프·STEP·번호·체크 칩·지도 핀·가격 태그·따옴표·퀴즈·티커·날짜·댓글 말풍선·비교·숫자 카운트·점 진행), 전환 5종(겹치기·밀기·확대·사선 와이프·바로).
- 글꼴은 Pretendard 하나(굵기 700/800/900)만 씁니다.
- 배경음악·내레이션 넣기(배경음악 파일이 없으면 스타일에 맞는 **스타일 음악** 10가지 분위기 중 하나를 코드로 만들어 깔아 줌 — 미리듣기·직접 고르기·끄기 가능), "장면 길이를 내레이션에 맞추기", MP4(크롬·엣지)/WEBM 저장, 자막 SRT, 프로젝트(.json) 저장·열기.
- **내레이션 만들기(제미나이·일레븐랩스·Fish Audio API 키)**: 소리 패널의 "내레이션 만들기"에서 서비스를 고르고 내 API 키를 넣으면 장면 자막(별표 뺀 글)을 그 목소리로 만들어 내레이션 자리에 바로 넣습니다. 키는 브라우저에서 각 서비스로 바로 가고(Fish Audio 만 이 사이트 서버가 한 번 전달), 서버에 저장되지 않습니다. "이 브라우저에 기억"을 켜면 내 브라우저에만 남습니다.
  - 제미나이: https://aistudio.google.com → **Get API key** (목소리 8가지 중 고르기)
  - 일레븐랩스: https://elevenlabs.io → Profile → **API Keys** (목소리는 Voice ID 를 넣음)
  - Fish Audio: https://fish.audio → **API Keys** (음성 모델 ID 기본값은 「밝은 고상철」, 엔진 Drama 3 / S2.1 Pro / S1, 속도 조절 가능 — 인터넷 배포 버전(ko372.com)에서만 됨)
- **AI 대본 만들기**: 주제·유형·장면 수를 넣으면 Claude가 고른 스타일의 뼈대(훅 → 장면 순서)에 맞춰 자막·제목·유튜브 설명·해시태그를 씁니다.

### 02 대표 이미지 합성
- 메인 사진 여러 장 + 서브 사진(구성품·라벨·로고)을 정사각형 캔버스에 같은 자리로 일괄 합성.
- 미리보기에서 서브 사진을 끌어서 위치 조정, 크기·테두리·모서리·그림자, "1+1 특가" 같은 문구 뱃지.
- JPG/PNG/WEBP, 파일 이름 규칙(`{name}`, `{n}`), ZIP 또는 PC 폴더로 저장.

### 03 이미지 일괄 다운로드
- 엑셀에서 상품 코드·이미지 주소를 복사해 표에 붙여 넣기(여러 줄·두 칸 동시 지원).
- 파일 이름 바꾸기(`앞글자_상품코드_뒷글자`), 크기 맞추기(300~1500px), 압축 4단계, 요청 간격 3단계.
- PC에 있는 사진도 같은 규칙으로 일괄 변환.
- 사이트가 직접 받기를 막으면 서버 프록시(`api/proxy.js`)가 대신 받습니다(Vercel 배포 시).

## 바로 써 보기 (내 PC)

```bash
cd mrk-video
python3 -m http.server 5173
# 브라우저에서 http://localhost:5173 열기
```

이렇게 열면 영상 만들기·합성·PC 사진 변환은 모두 동작합니다. AI 대본과 서버 프록시는 아래 Vercel 배포(또는 `npx vercel dev`)에서 켜집니다.

## 인터넷에 올리기 (Vercel, 무료 요금제로 충분)

1. https://vercel.com 에 GitHub 계정으로 로그인 → **Add New… › Project** → 이 저장소(`rsa`) 선택
2. **Root Directory**를 `mrk-video`로 지정 (Framework Preset은 `Other`)
3. **Environment Variables**에 아래 두 값을 넣고 **Deploy**

| 이름 | 값 | 용도 |
|---|---|---|
| `ANTHROPIC_API_KEY` | console.anthropic.com에서 발급한 키 | AI 대본 |
| `ACCESS_CODE` | 내가 정한 비밀 문구 | 남이 내 키·서버를 쓰지 못하게 막음 (ko372.com 에서는 `MRK_VIDEO_ACCESS_CODE`) |
| `YOUTUBE_API_KEY` | (선택) YouTube Data API v3 키 | 빵터진 영상 찾기 |

배포가 끝나면 `https://<프로젝트이름>.vercel.app` 주소가 생깁니다. 처음 접속하면 **사용 안내** 탭에서 접속 코드를 한 번 입력하세요(그 브라우저에 기억됩니다).
`ACCESS_CODE`를 넣지 않으면 AI 기능은 꺼진 채로 동작합니다.
ko372.com(`/mrk-video/`)에서는 **회원 전용**입니다: 자동화 기수별 회원 코드(`MRK_VIDEO_MEMBER_CODES`)로 들어오면 화면 맨 위에 "회원 전용 · 자동화 N기 회원"과 나가기 버튼이 보입니다(이 단독 배포에는 입장 게이트가 없어 표시도 나오지 않음).

GitHub에 새 커밋을 올리면 Vercel이 자동으로 다시 배포합니다.

## 폴더 구조 — 어디를 고치면 무엇이 바뀌나

```
mrk-video/
├─ index.html            화면 뼈대(메뉴·입력 칸·버튼). 문구를 바꾸려면 여기
├─ css/style.css         색·글꼴·배치. 맨 위 :root의 색 변수만 바꿔도 분위기가 바뀝니다
├─ js/
│  ├─ main.js            메뉴 전환, 사용 안내의 환경 표시
│  ├─ shorts.js          숏폼 화면: 스타일 갤러리, 장면 목록, 미리보기, 소리, 내보내기(한 편/30가지 전부), 바로 올리기
│  ├─ shorts-render.js   영상 한 프레임을 그리는 엔진(레이아웃·자막 등장·장식·전환) ← 영상 모양은 여기
│  ├─ styles-data.js     잘 나가는 쇼츠 스타일 30가지 데이터 ← 스타일을 추가·수정하려면 여기 (형식: docs/STYLE-SPEC.md)
│  ├─ styles.js          스타일을 프로젝트에 입히는 도구
│  ├─ export.js          MP4/WEBM 내보내기(한 편, 여러 스타일)
│  ├─ showcase.js        사례 보기 화면
│  ├─ motion.js          화면 움직임(키네틱 글자, 패널 떠오르기, 화면 전환)
│  ├─ samples.js         예시 이미지 로더(실사 없으면 그림으로 대체)
│  ├─ script-prompt.js   AI 대본 프롬프트와 결과 형식 ← AI 말투·규칙은 여기
│  ├─ compose.js         대표 이미지 합성
│  ├─ downloader.js      이미지 일괄 다운로드
│  ├─ tts.js             내레이션 만들기(제미나이·일레븐랩스는 브라우저에서 직접, Fish Audio 는 api/tts 중계)
│  ├─ platform.js        파일 저장·AI 호출·Fish Audio 중계를 환경(Claude 아티팩트/웹)에 맞게 처리
│  └─ util.js            공용 도구, 예시 그림
├─ api/                  Vercel 서버 함수 (ko372.com 에서는 lib/mrk-video/*.mjs 로 같은 내용)
│  ├─ ai.js              AI 대본 (Claude API, fetch 직접 호출)
│  ├─ tts.js             Fish Audio 내레이션 중계(사용자 키를 그대로 전달, 저장 안 함)
│  ├─ proxy.js           이미지 프록시 (내부망 차단·이미지만·20MB 제한)
│  ├─ youtube.js         빵터진 영상 찾기(유튜브 검색 프록시)
│  └─ health.js          서버 기능 켜짐 여부
├─ assets/
│  ├─ fonts/             Pretendard Variable (자체 호스팅)
│  ├─ samples/           힉스필드로 만든 예시 실사 이미지
│  ├─ guide/             사용 안내 단계별 캡처(step-01~06.jpg)
│  └─ video/             사용법 영상(tutorial.mp4, 포스터 tutorial-poster.jpg) — 없으면 안내 화면의 영상 칸이 숨겨짐
├─ tests/                스타일 30종 스냅샷 시트(style-sheet.cjs)
├─ scripts/artifact-page.mjs   Claude 아티팩트용 페이지 만들기
└─ docs/ANALYSIS.md      설치 파일 분석 보고서
```

빌드 도구가 없는 순수 HTML·CSS·JavaScript라서, 파일을 고치고 새로고침하면 바로 반영됩니다.

## 바이브 코딩으로 키워 가기

Claude Code에서 이 폴더를 열고 하고 싶은 것을 말하면 됩니다. 예:

- "styles-data.js에 '경매 물건 분석형' 스타일을 추가해줘. 검은 배경에 숫자 카운트 장식"
- "AI 대본 유형에 '경매 물건 분석'을 추가해줘"
- "합성 화면에 워터마크 글자(대각선 반복) 옵션 넣어줘"
- "영상에 장면마다 다른 배경음악 구간을 넣을 수 있게 해줘"
- "내레이션 녹음을 브라우저에서 바로 할 수 있게 해줘"

규칙과 구조 설명은 [CLAUDE.md](CLAUDE.md)에 있어 Claude가 자동으로 참고합니다.

## 알아 둘 점

- 영상은 실제 길이만큼 녹화하듯 만듭니다(30초 영상 ≈ 30초). 만드는 동안 탭을 띄워 두세요.
- 사진·소리는 서버로 올라가지 않습니다. 서버로 가는 것은 AI 대본 요청(주제 글), 프록시로 받는 이미지 주소, 그리고 Fish Audio 내레이션 요청(내 키·대본 — 전달만 하고 저장하지 않음)뿐입니다.
- AI가 쓴 법령·수치는 올리기 전에 꼭 확인하세요.
