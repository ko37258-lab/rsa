## 2. 설치 파일 내부

- 형식: `PE32 실행 파일 (GUI) Intel 80386 Mono/.Net assembly` — .NET Framework 4 WPF 프로그램
- 내부 이름: `StoreInstaller` (빌드 경로 `D:\a\_work\1\s\src\StoreInstaller\…`)
- 서명: Microsoft Marketplace CA → Microsoft Root CA 2011 체인
- 하는 일: 인증서 서명 영역에 붙은 꼬리표(`MSStoreTag001`)를 읽어 어떤 앱을 깔지 알아낸 뒤, Windows 스토어(Windows Update 경로)로 앱을 내려받아 설치합니다. 설치 진행 화면, 연령 등급 표시, 지역·OS·CPU 호환성 검사, 설치 통계 전송 코드가 들어 있습니다.
- 꼬리표 내용(압축 해제 결과, 주요 값만):

```json
{
  "productId": "9NDBK049JS8Z",
  "pfns": ["sellergram.554883376DF75_7hqmypcb323bg"],
```

즉, 이 파일을 아무리 뜯어봐도 "메이커 셀링 도우미"의 실제 동작 코드는 나오지 않습니다. 앱 본체는 설치 시점에 스토어에서 따로 내려받습니다.

### 화면 구성 (스크린샷 기준)

왼쪽 세로 메뉴 3개: **대표 이미지 대량 다운로드 / 대표 이미지 대량 합성 / 숏폼 영상 생성기**

대표 이미지 대량 다운로드 화면:

| 영역 | 내용 |
|---|---|
| 목록 표 | `#`, 상품 코드, 이미지 URL, 저장 정보, 상태, 삭제. 셀을 누르고 Ctrl+V로 여러 줄 붙여넣기 |
| 버튼 | 샘플 채우기, 행 추가, 초기화 |
| 저장 폴더 | 경로 입력, 폴더 선택, 폴더 열기 |
| 파일명 변경 | `앞글자 _ 상품코드 _ 뒷글자 . 확장자` |
| 크기 변경 | 가로 × 세로 (300~1500px) |
| 용량 줄이기 | 압축 단계 선택 (예: 표준 압축) |
| 다운로드 요청 간격 | 예: 1.0~2.0초 (안정성 보통) |
| 하단 | 입력 URL 수, 유효 URL 수, 진행률, 다운로드 시작 |

대표 이미지 대량 합성(스토어 설명): 메인 이미지와 서브 이미지를 1000×1000 캔버스에 배치해 일괄 합성, 서브 이미지 크기·위치를 실시간 미리보기로 조절.

숏폼 영상 생성기: 메뉴만 확인되고 공개 설명은 없음 → MR.K 버전에서는 독자적으로 설계.

## 5. 저작권·이용약관 관련 판단

- 기능 아이디어(대량 다운로드, 합성, 숏폼 생성)는 보호 대상이 아니지만, **원본 앱의 코드·디자인 자산·이름·로고를 복제하는 것은 저작권 침해와 이용약관 위반 소지가 있습니다.** 그래서 앱 본체(MSIX)를 내려받아 디컴파일하지 않았고, 공개 설명과 스크린샷의 기능 목록만 참고해 새로 만들었습니다.
- 이름은 "MR.K 영상만들기", 로고·색·글꼴·문구는 모두 새로 정했습니다.
- 이미지 일괄 다운로드는 본인 상품이거나 사용 권한이 있는 이미지에만 쓰도록 화면에 안내했습니다.
