스마트 앱 컨트롤 때문에 '설치' 가 막힐 때
==========================================

윈도우 11 의 '스마트 앱 컨트롤'은 인터넷에서 받은 .bat / .vbs 파일을 막습니다.
(바이러스라서가 아니라, 이런 종류의 파일은 무조건 막는 기능입니다. '그래도 실행' 단추가 없습니다.)
아래 방법 1 → 안 되면 방법 2 순서로 해 보세요.


[방법 1] '인터넷에서 받은 파일' 표시 지우고 다시 설치
----------------------------------------------------
1. 프로그램 폴더를 엽니다. (설치.bat 이 있는 폴더)
2. 창 위쪽 주소창을 한 번 누르고, 글자를 지운 뒤  powershell  이라고 쓰고 Enter.
   → 그 폴더에서 파란(또는 검은) PowerShell 창이 열립니다.
3. 아래 한 줄을 복사해서 붙여넣고 Enter:

Get-ChildItem -Recurse | Unblock-File

4. 이제 '설치.bat' 을 다시 두 번 눌러 보세요.


[방법 2] 파일 없이 명령어로 설치 (방법 1 로도 막힐 때)
----------------------------------------------------
1. 위 방법 1 의 1~2 번처럼 프로그램 폴더에서 PowerShell 창을 엽니다.
2. 아래 7줄을 통째로 복사해서 붙여넣고 Enter.
   ('여러 줄을 붙여넣으려고 합니다' 경고가 뜨면 '그래도 붙여넣기')
   10~20분 걸립니다. 파이썬이 없던 컴퓨터는 중간에 파이썬 설치 창이 뜰 수 있어요.

$py = (Get-Command py -ErrorAction SilentlyContinue).Source
if (-not $py) { winget install -e --id Python.Python.3.12 --scope user --accept-package-agreements --accept-source-agreements; $py = "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" }
& $py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m reels_autopilot fonts
.\.venv\Scripts\python.exe -m reels_autopilot shortcut

3. 끝나면 바탕화면에 '릴스 만들기' 가 생깁니다. 두 번 누르면 프로그램이 열립니다.
   (내 컴퓨터에서 새로 만든 바로가기라서 스마트 앱 컨트롤에 막히지 않습니다.)
   바로가기가 안 열리면 PowerShell 창에서 아래 한 줄로도 켤 수 있습니다:

.\.venv\Scripts\python.exe -m reels_autopilot ui


그래도 막힐 때
--------------
- 설치는 됐는데 '스마트 앱 컨트롤이 이 앱의 일부를 차단했습니다' 가 뜨면,
  인증서 서명이 없는 부품(영상·계산용 프로그램 조각)을 막은 것입니다.
  이때는 화면의 '기록 복사' 내용이나 메시지 사진을 보내 주세요.
- 마지막 방법: Windows 보안 > 앱 및 브라우저 컨트롤 > 스마트 앱 컨트롤 > 끔.
  단, 2026년 10월 윈도우 업데이트 이후 일부 PC 에서는 한 번 끄면 다시 켜는 단추가
  회색으로 막히는 문제가 보고되어 있으니, 방법 1·2 를 먼저 해 보세요.
