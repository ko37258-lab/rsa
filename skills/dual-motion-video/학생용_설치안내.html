듀얼 모션 비디오 스킬 설치 안내

영상 파일 하나를 넣으면 Claude가 모션그래픽, 자막, 효과음을 넣어 유튜브 본편과 쇼츠를 한 번에 만듭니다. 처음 한 번만 설치하면 그다음부터는 한 문장으로 실행됩니다.

16:9 본편인트로 · 챕터 · 정보카드 · 상담 CTA
9:16 쇼츠핵심 구간 1분 · 큰 자막 · 카드

준비물

설치 전에 세 가지를 확인하세요.

  1. Claude 유료 요금제 (Pro 이상)

    스킬은 Claude 데스크톱 앱의 Code 탭에서 실행합니다. Code 탭은 Pro 요금제부터 쓸 수 있습니다.

  2. Claude 데스크톱 앱

    claude.ai/download에서 Windows 또는 Mac용 앱을 설치하고 로그인합니다.

  3. Python

    python.org/downloads에서 설치합니다. Windows는 설치 첫 화면 아래쪽의 "Add python.exe to PATH"에 꼭 체크하세요.

    Python을 직접 설치하기 어렵다면 3번 설치 단계에서 Claude에게 "Python도 설치해줘"라고 덧붙이면 안내해 줍니다.

스킬 설치 (처음 한 번)

교수님이 공유한 dual-motion-video.zip 파일을 내려받은 뒤 아래 방법 중 하나를 고르세요.

  1. Code 탭 열기

    Claude 데스크톱 앱 왼쪽 위에서 Code를 누르고, 폴더는 다운로드 폴더를 고릅니다.

  2. 아래 문장을 그대로 붙여넣기

    다운로드 폴더에 있는 dual-motion-video.zip을 내 사용자 스킬 폴더(~/.claude/skills/dual-motion-video)에 압축을 풀어 설치하고, 그 안의 scripts/setup_check.py --install 을 실행해서 필요한 프로그램까지 준비해줘.

    Claude가 명령 실행을 물어보면 허용을 누르세요. 처음에는 5~10분 걸립니다.

  3. "준비 완료!" 확인

    마지막에 준비 완료!가 보이면 설치가 끝난 것입니다. 앱을 한 번 껐다 켜면 스킬이 인식됩니다.

  1. 압축 풀기

    zip 파일을 마우스 오른쪽 버튼으로 누르고 압축 풀기를 선택합니다. 그러면 dual-motion-video 폴더가 생깁니다.

  2. 스킬 폴더 열기

    Windows는 파일 탐색기 주소창에 아래를 붙여넣고 Enter를 누릅니다. 폴더가 없다는 메시지가 나오면 .claude 안에 skills 폴더를 새로 만드세요.

    %USERPROFILE%\.claude\skills

    Mac은 Finder에서 Cmd+Shift+G를 누르고 ~/.claude/skills를 입력합니다.

  3. 폴더 넣기

    dual-motion-video 폴더를 통째로 옮깁니다. 최종 위치는 …\.claude\skills\dual-motion-video\SKILL.md여야 합니다. 폴더가 두 겹(dual-motion-video 안에 또 dual-motion-video)이 되지 않게 주의하세요.

  4. 필요한 프로그램 설치

    Code 탭에서 "dual-motion-video 스킬 준비해줘"라고 입력하면 Claude가 설치 점검을 실행합니다.

영상 만들기 (매번)

설치 후에는 영상만 바꿔서 이 순서대로 하면 됩니다.

  1. 영상이 있는 폴더로 Code 탭 열기

    새 세션을 시작할 때 영상 파일이 들어 있는 폴더를 고릅니다.

  2. 한 문장으로 요청

    이 폴더의 매물영상.mp4로 모션그래픽 넣은 16:9 본편이랑 9:16 쇼츠 만들어줘. 유튜브 제목이랑 설명도 정리해줘.

    파일 이름은 본인 영상 이름으로 바꾸세요. 입력창에 /dual-motion-video를 쳐서 스킬을 직접 불러도 됩니다.

  3. 미리보기 확인

    Claude가 미리보기 그림을 먼저 보여 줍니다. 고칠 곳이 있으면 "전화번호 카드를 오른쪽으로", "쇼츠 첫 장면을 거실 장면으로"처럼 말로 요청하세요.

  4. 완성 파일 받기

    5분짜리 영상 기준으로 15~40분 걸립니다. 노트북은 전원을 연결해 두세요. 완성 파일은 영상 폴더 안 output 폴더에 생깁니다.

다른 사람의 영상, 사진, 음악은 사용 허락을 받은 것만 쓰세요. 스킬은 영상에서 말하거나 화면에 나온 정보만 넣고, 근거 없는 숫자는 넣지 않도록 만들어져 있습니다.

자주 묻는 질문

"python을 찾을 수 없습니다"라고 나와요

Python 설치 때 PATH 체크를 안 한 경우입니다. Python을 다시 설치하면서 "Add python.exe to PATH"에 체크하세요.

너무 오래 걸리거나 컴퓨터가 멈춰요

"작업 수를 1로 줄여서 다시 렌더링해줘"라고 요청하세요. 느려지지만 메모리를 덜 씁니다.

회사 PC라 설치가 막혀요

보안 정책으로 브라우저 엔진 다운로드가 막히는 경우가 있습니다. "설치된 크롬을 써서 실행해줘"라고 요청하면 됩니다.

claude.ai 웹 채팅에서도 되나요?

스킬 zip을 웹 설정에 올릴 수는 있지만, 영상 파일 크기 제한과 프로그램 설치 제한 때문에 영상 제작은 내 컴퓨터에서 돌아가는 Code 탭을 권장합니다.
