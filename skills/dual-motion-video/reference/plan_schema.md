# plan.json 작성 규칙

`render.py`는 이 파일 하나만 읽고 16:9 본편과 9:16 쇼츠를 만든다. **모든 시간은 원본 영상 기준 초(秒)**다. 쇼츠도 원본 시간으로 적으면 엔진이 쇼츠 타임라인으로 자동 변환한다.
글자에는 HTML을 쓸 수 있다: `<b>강조</b>`(자막에서 노란색), `<g>금색</g>`, `<br>`(줄바꿈).

## 최상위

| 키 | 필수 | 설명 |
|---|---|---|
| `name` | ○ | 결과 파일 이름 앞부분 (`{name}_16x9.mp4`, `{name}_9x16_쇼츠.mp4`) |
| `source` | ○ | 원본 영상 경로 (plan.json 기준 상대경로 가능) |
| `theme` | | `navy-gold`(기본, 고급 부동산) · `red`(강렬/할인) · `mint`(산뜻/생활) · `blue`(신뢰/교육) |
| `brand` | | `{"name": "채널/업체명", "phone": "전화번호"}` → 인트로·쇼츠 상단·CTA에 자동 사용. **영상에 나온 번호만** 쓴다 |
| `title` | ○ | `{"kicker": "작은 영문 문구", "main": "큰 제목", "sub": "부제"}` |
| `out_dir` | | 결과 폴더 (기본 `output`) |
| `landscape` | | 16:9 본편 설정. 없으면 본편을 만들지 않음 |
| `shorts` | | 9:16 쇼츠 설정. 없으면 쇼츠를 만들지 않음 |

## landscape (16:9, 1920×1080)

```json
"landscape": {
  "intro": {"end": 15.8, "blur": true, "chips": ["핵심1","핵심2","핵심3"], "stamp": "강조 도장 🔥",
            "counter": {"label": "총 1,976세대 중", "from": 1976, "to": 8, "unit": "세대"}},
  "zoom": [[16, 42.4, 0.06]],
  "chapters": [[43.3, 72.2, "① 희소성"], [73.6, 91.9, "② 입지"]],
  "items": [ ... 아래 '아이템' ... ]
}
```
- `intro`: 원본 앞부분(정지 배너, 인사말 등)을 흐리게 깔고 제목·칩·도장·카운터·전화번호 카드가 순서대로 등장한다. `end`는 인트로 끝 시각이다. 원본이 그 시각에 장면이 바뀌면 가장 자연스럽다. 인트로가 필요 없으면 키를 뺀다. `counter`도 선택 항목이다.
- `zoom`: `[시작, 끝, 확대량]`. 진행자가 말하는 고정 샷에서 화면이 천천히 다가가는 효과다. 0.04~0.08을 권장한다. **끝 시각은 장면이 바뀌는 지점**으로 잡아야 확대가 풀리는 순간이 티 나지 않는다.
- `chapters`: 화면 위 가운데에 지금 주제를 띄운다. 첫 챕터가 1초 이후에 시작하면 `youtube_chapters.txt`에 `00:00 오프닝`이 자동으로 붙는다.

## shorts (9:16, 1080×1920)

```json
"shorts": {
  "segments": [[30.45, 38.15], [43.3, 56.98]],
  "chapters": ["🔥 훅 문구", "💎 두 번째 구간 주제"],
  "captions": [[30.6, 34.85, "바로 <b>더샵 일산 엘로이</b><br>75평형 펜트하우스가"]],
  "items": [ ... ],
  "tail": {"dur": 1.8, "text": "📞 지금 바로 전화 주세요!"}
}
```
- `segments`: 원본에서 잘라 이어 붙일 구간이다. 합계 **45~75초**를 권장하고, 최대 180초까지 가능하다. 첫 구간은 가장 강한 훅으로, 마지막 구간은 상담·구독 요청(CTA)으로 둔다. 자르는 지점은 `transcript.json`의 **단어 시작·끝 시각에서 0.1~0.2초 여유**를 둔다. 문장 중간은 자르지 않는다.
- `chapters`: 구간마다 하나씩 넣는다. 영상 위쪽 금색 칩으로 나온다.
- `captions`: `[시작, 끝, 문구]`. 영상 아래 큰 자막이다. 한 줄 16자 안팎, 최대 2줄로 쓴다. **음성 인식 오타는 화면 글자와 문맥으로 바로잡는다** (예: 앨로이→엘로이, 캔트하우스→펜트하우스). 구간 밖 시간은 쓰지 않는다.
- `tail`: 마지막 장면을 멈춘 채 끝 인사 카드를 보여주는 시간이다. 0이면 끈다.
- 쇼츠 화면 배치:
  - 위 0~600px: 제목 영역
  - 600~1208px: 영상 (16:9 원본 기준)
  - 1310px 부근: 자막
  - 1520px 부근: 카드
  - 1650px 아래: 쇼츠 앱의 제목·버튼이 덮는 영역이라 비워 둔다

## 아이템 (landscape.items / shorts.items 공통)

모든 아이템은 `t`(등장)와 `out`(퇴장)을 가진다. 쇼츠에서는 `out`을 `"end"`로 쓸 수 있다. `pos: [x, y]`는 중심 좌표이고, 생략하면 형식별 기본 위치에 놓인다. `anim`으로 등장 방식을 바꿀 수 있다: `pop`·`slam`·`stamp`·`rise`·`slideL`·`slideR`·`drop`.

| type | 필드 | 쓰임 |
|---|---|---|
| `card` | `title`(작은 영문), `lines`([작은 줄]), `big`(금색 큰 글), `size` | 핵심 정보 카드 |
| `stamp` | `text`, `size`, `rot`(기울기) | "파격 혜택!" 같은 빨간 도장. 쿵 효과음과 번쩍임이 함께 나온다 |
| `chip` | `text`, `size` | 금색 알약 모양 문구 |
| `row` | `icon`(이모지), `text` | 아이콘+문구 한 줄 |
| `rows` | `title`, `rows: [[t, icon, text], ...]`, `gap` | 체크리스트. 줄마다 **말하는 순간** 하나씩 등장한다. 쇼츠에서 4줄 이상이면 2열로 배치된다 |
| `counter` | `label`, `from`, `to`, `unit`, `count: [시작, 끝]` | 숫자가 바뀌는 카운터 (예: 1,976→8) |
| `quote` | `small`, `big` | 명언·결론 카드 |
| `cta` | `title`, `phone`, `name` | 깜빡이는 전화 상담 카드 (brand 정보 자동 사용) |
| `subscribe` | `click` | 구독·좋아요·알림 버튼을 마우스가 누르는 장면 |
| `text` | `html` | 자유 HTML (특수한 경우만) |

16:9 기본 위치:
- `card` [330,430] (왼쪽)
- `stamp` [1590,430]
- `rows` [1620,300] (오른쪽 세로 목록)
- `quote` [960,250]
- `cta` [1560,420]
- `subscribe` [1540,780]

**원본에 이미 있는 자막·그래픽·얼굴을 가리지 않는 쪽**에 놓는다. 위치는 contact sheet와 `--preview`로 확인한다.

## 효과음

효과음은 아이템 종류에 따라 자동으로 들어간다. 따로 설정하지 않아도 된다.
- 카드·칩·줄: 팝
- 도장·인용: 쿵 + 반짝 + 화면 번쩍임
- 챕터 전환·쇼츠 컷: 휙
- 카운터: 틱틱틱 + 띵
- 구독: 클릭

특정 아이템에 `"sfx": "pop|impact|whoosh|ding"`을 넣으면 바꿀 수 있다.
