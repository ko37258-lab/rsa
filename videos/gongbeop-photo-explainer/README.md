# 사진 두 장 설명 영상 (공법의 신)

강의 현장 사진과 AI로 그린 작업실 사진을 하나씩 짚어 주는 138초 영상입니다.
모션그래픽 영상꾸미기 스타일(종이 배경, 키네틱 제목, 흰 카드, 가라오케 자막)로 만들었습니다.

- 목소리: Fish Audio 「밝은 고상철」 (`reference_id 440b9066d8d64a988638af6e2820dc4b`, 모델 s1, 1.15배속)
- 화면: Remotion 4.0.526, 1920×1080, 30fps

## 파일
| 파일 | 내용 |
|---|---|
| `script.json` | 대본과 연출표. 문장마다 `say`(읽을 글), `show`(자막 글), `ev`(카메라 이동, 강조 상자, 배지, 패널, 꽃가루) |
| `build.py` | 문장별 음성 생성 → 잘림 검사(끝 0.05초 피크 비율 0.12 초과면 다시 생성) → 이어 붙이기 → 음성인식으로 단어 시점 측정 → `public/voice.wav`, `src/timeline.json`, `src/subs.json` |
| `src/index.tsx` | 화면 구성 (인트로, 사진 카드, 03단계 공식 패널, 마무리 명언 카드) |
| `stills.mjs` | 확인용 정지 화면 여러 장 렌더 |

## 다시 만들기
1. 이 폴더의 `public/`에 넣을 파일
   - `photo1.webp`(강의 현장), `photo2.webp`(AI 작업실). 수강생 얼굴이 있어 저장소에는 넣지 않았습니다.
   - 모션그래픽 영상꾸미기 스킬의 `assets/template/public/`에 있는 `fonts/`, `face.webm`
2. 설치: `npm install` 그리고 `pip install faster-whisper numpy`
3. 음성과 타임라인: `FISH_API_KEY=<키> python3 build.py`
   - 같은 문장은 `tts/`에 저장해 두고 다시 쓰므로, 대본을 고치면 바뀐 문장만 새로 만듭니다.
4. 확인: `node stills.mjs 4.6 24.3 86.6` (초 단위, `stills/`에 저장)
5. 렌더: `npx remotion render src/index.tsx Decor out.mp4 --codec=h264 --crf=18 --concurrency=4`

## 내용 확인
- 용적률 최대한도: 「국토의 계획 및 이용에 관한 법률」 제78조 제1항 (주거 500%, 상업 1,500%, 공업 400%, 녹지 100% 이하)으로 대조했습니다.
  AI 그림 속 화이트보드 숫자(주거 200%, 상업 800%)는 실제와 달라서, 영상에서 "그림 속 예시"라고 짚고 법 기준을 따로 보여 줍니다.
- 건폐율·용적률 정의(건축법 제55조·제56조)와 아파트 복도가 공용부분이라는 내용(집합건물법 제3조·제10조)은 조문 원문 대조를 따로 하지 않았습니다.
