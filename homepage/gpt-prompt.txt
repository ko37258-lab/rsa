[ChatGPT 또는 Claude에 ZIP 파일을 첨부하고, 아래 글을 붙여 넣으세요]
※ ○○ 부분만 내 사무소 정보로 바꾼 뒤, 줄 전체를 복사해서 붙여 넣으면 됩니다.

------------------------------------------------------------
첨부한 ZIP 파일은 공인중개사무소 홈페이지 템플릿이야. 코드 실행(파이썬) 기능으로 아래 순서대로 작업해 줘.

1. ZIP을 풀어. 안에 mrhomes-homepage 폴더가 있어.

2. mrhomes-homepage/js/my-office.js 파일을 열고, 따옴표 안의 빈칸 5개를 아래 정보로 채워.
   name    = ○○공인중개사사무소
   address = ○○시 ○○구 ○○로 00, 0층 000호 (○○동)
   phone   = 000-000-0000
   regNo   = 00000-0000-00000
   broker  = ○○○
   - 따옴표, 쉼표, 주석(// 뒤의 글자)과 다른 줄은 그대로 둬.
   - 내가 준 글자를 한 글자도 바꾸거나 보태지 마.

3. mrhomes-homepage/index.html 위쪽에서 아래 두 줄의 content 값만 바꿔.
   og:title       → ○○공인중개사사무소 | ○○동 부동산
   og:description → ○○동 아파트·주택·상가·토지 중개 · 000-000-0000

4. 위 두 파일 말고 다른 파일은 건드리지 마.

5. 바꾼 부분을 바꾸기 전 / 바꾼 후로 나란히 보여 줘.

6. 폴더 구조(mrhomes-homepage/…)를 그대로 유지한 채 다시 ZIP으로 묶어서 내려받기 링크를 줘. 파일 이름은 my-homepage.zip 으로 해 줘.
------------------------------------------------------------

[받은 다음에 할 일]
1. my-homepage.zip 을 내려받아 압축을 풉니다.
2. mrhomes-homepage 폴더의 index.html 을 열어, 맨 위 이름과 맨 아래 법정 표시사항(명칭·소재지·연락처·등록번호·대표자)이 등록증과 같은지 확인합니다.
3. https://app.netlify.com/drop 에 mrhomes-homepage 폴더를 끌어다 놓으면 인터넷 주소가 생깁니다.
4. 매물과 사진은 그다음에 천천히 바꿉니다. (guide.html 5·6번)
