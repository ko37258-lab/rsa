설정 파일 하나로 완성하기

미스터홈즈 서초 부동산 홈페이지를 그대로 본떠 쓸 수 있게 만든 템플릿입니다. 코딩을 몰라도 js/config.js 한 파일의 글자만 바꾸면 사무소 이름, 연락처, 대표 소개, 지하철 길 안내 애니메이션까지 내 사무소로 바뀝니다.

01압축 풀고 열어 보기

  1. 내려받은 mrhomes-homepage-template.zip을 마우스 오른쪽 클릭 → 압축 풀기.
  2. mrhomes-homepage 폴더 안의 index.html을 더블클릭하면 크롬·엣지에서 홈페이지가 열립니다.
  3. 지금은 예시로 미스터홈즈 서초 부동산 정보가 들어 있습니다. 아래 순서대로 내 정보로 바꾸면 됩니다.
준비물메모장(윈도우 기본) 또는 무료 편집기 VS Code, 사무소·매물 사진, 중개사무소 등록증.

03사무소 정보 바꾸기 — js/config.js

메모장으로 js/config.js를 열고, 따옴표 안의 글자만 바꿉니다. 저장한 뒤 index.html을 새로고침(F5)하면 바로 반영됩니다.

office: "미스터홈즈 부동산중개",   // 등록증의 중개사무소 명칭
address: "서울특별시 강남구 봉은사로 404, 2층 202호 (삼성동)",
phone: "02-566-0338",
regNo: "11170-2016-00105",    // 중개사무소 등록번호
broker: "고상철",              // 개업공인중개사 성명
이 다섯 줄은 법정 표시사항입니다공인중개사법 제18조의2에 따라 홈페이지(표시·광고)에는 중개사무소 명칭·소재지·연락처·등록번호·개업공인중개사 성명을 반드시 적어야 합니다. 등록증과 한 글자도 다르지 않게 넣으세요.

지켜야 할 세 가지

  • 따옴표 ", 쉼표 ,, 괄호 [ ] { }는 지우지 않습니다.
  • 글자 안에 큰따옴표가 필요하면 작은따옴표 ‘ ’를 씁니다.
  • 저장할 때 인코딩은 UTF-8(메모장 기본값)을 유지합니다.

맨 위 큰 문구

title: ["삼성동의 최상위 매물 보유한", "신뢰와 실력으로 *전문중개*합니다."],

한 줄씩 나뉘어 보이고, *별표*로 감싼 글자는 빨간색으로 강조됩니다. 대표 소개(ceo), 강점 3가지(expert), 거래 순서(process), 상담 구역(contact)도 같은 방식입니다.

04지하철 길 안내 지도 — 좌표만 넣기

“오시는 길”의 애니메이션 지도는 config.js의 map 부분 좌표로 자동으로 그려집니다. 좌표는 구글 지도에서 얻습니다.

  1. 구글 지도에서 원하는 지점을 마우스 오른쪽 클릭합니다.
  2. 메뉴 맨 위의 숫자(예: 37.5101, 127.0443)를 누르면 복사됩니다.
  3. [37.5101, 127.0443]처럼 대괄호 안에 위도, 경도 순서로 붙여 넣습니다.
항목찍을 지점
center역 앞 사거리 한가운데
roads사거리를 이루는 큰길(최대 2개). toward는 그 길 위로 200m쯤 떨어진 아무 점
lines노선 이름·색·몇 번째 길 밑인지(road: 0 또는 1). at은 역 위치(선택)
exits출구 번호와 위치. 찾아오는 출구에 target: true
office사무소 건물 위치, 건물 이름, 층·호수
walk출구 → 건물 입구까지 꺾이는 지점들(선택). 비워 두면 직선
landmarks, bus주변 건물·버스 정류장(선택)

노선 공식 색: 1호선 #0052A4 · 2호선 #00A84D · 3호선 #EF7C1C · 4호선 #00A5DE · 5호선 #996CAC · 6호선 #CD7C2F · 7호선 #747F00 · 8호선 #E6186C · 9호선 #BDB092 · 수인분당선 #F5A200 · 신분당선 #D4003B

확인 방법저장 후 새로고침하고 “지하철에서 오시는 길 재생”을 눌러 보세요. 출구에서 건물까지 선이 이어지면 성공입니다. 지도는 실제 축척이라 출구 위치가 정확할수록 보기 좋습니다.

05매물 바꾸기 — js/listings.js

FEATURED는 맨 위 대표 매물 2개, CASES는 유형별 사례 6개입니다. 대표 매물의 legal 항목은 “상세 · 법정 표시사항” 창에 그대로 나옵니다.

인터넷 매물 광고의 필수 항목 (공인중개사법 시행령 제17조의2)소재지 · 면적 · 가격 · 중개대상물 종류 · 거래 형태 · 총 층수 · 사용승인일 · 방향 · 방/욕실 수 · 입주가능일 · 주차대수 · 관리비. 해당 없는 항목은 “해당 없음”으로 적습니다. 면적은 ㎡로 쓰고 평은 괄호 병기만 합니다.
  • 실제 매물로 모두 바꾼 뒤 config.js의 SAMPLE_MODE: true를 false로 바꾸면 “예시” 표시가 사라집니다.
  • 계약이 끝난 매물은 status: "계약완료"로 바꾸면 화면에서 바로 빠집니다. 계약된 매물을 계속 올려 두면 허위·미끼 매물 광고에 해당합니다.
  • checked에는 매물을 마지막으로 확인한 날짜를 적습니다.

07카톡 미리보기 문구 — index.html 맨 위 3줄

카카오톡·문자로 홈페이지 주소를 보낼 때 뜨는 제목·설명은 프로그램이 읽기 전에 정해지므로, index.html 위쪽의 아래 3줄을 직접 바꿉니다.

<meta property="og:title" content="미스터홈즈 서초 부동산 | 삼성동 빌딩·토지·상가 전문중개">
<meta property="og:description" content="삼성동의 최상위 매물 보유한 … · 02-566-0338">
<meta property="og:image" content="images/hero.jpg">

08인터넷에 올리기 — 무료, 5분

  1. app.netlify.com/drop에 접속해 무료로 가입합니다.
  2. mrhomes-homepage 폴더째로 화면에 끌어다 놓습니다. (index.html이 들어 있는 폴더)
  3. 몇 초 뒤 https://○○○.netlify.app 주소가 생깁니다. 이 주소를 명함·블로그·카톡에 쓰면 됩니다.
  4. 사이트 설정(Site configuration) → 사이트 이름 변경에서 주소 앞부분을 사무소 이름으로 바꿀 수 있습니다.
  5. 수정할 때는 내 컴퓨터에서 고친 뒤 Deploys 화면에 폴더를 다시 끌어다 놓습니다.
내 도메인(예: www.○○부동산.com)을 쓰려면가비아·후이즈 등에서 도메인을 산 뒤 Netlify의 Domain management에서 연결합니다. 선택 사항입니다.

09상담 신청서 연결

그대로 두면 상담 신청 내용을 정리해 보여 주고 전화로 안내합니다. 신청서를 이메일로 받고 싶다면:

  1. formspree.io에 무료 가입 → New Form 만들기.
  2. 나오는 주소(예: https://formspree.io/f/abcdwxyz)를 복사합니다.
  3. config.js의 formEndpoint: "" 따옴표 안에 붙여 넣고 저장합니다.

카카오톡 채널이 있다면 kakaoChannel에 채널 주소를 넣으세요. 휴대폰 화면 아래에 “카톡 상담” 버튼이 생깁니다.

11올리기 전 점검표

  • 등록증과 똑같은 명칭·소재지·연락처·등록번호·대표자 이름 (config.js 맨 위 5줄)
  • 예시 매물(미스터홈즈 매물)을 모두 내 매물로 바꾸고 SAMPLE_MODE: false
  • 매물마다 법정 명시사항 12개 항목 채움, 면적은 ㎡ 기준
  • 예시 사진을 내 사진으로 교체 (특히 매물 사진은 실제 사진)
  • 대표 소개·이력·강점 문구를 내 내용으로 교체
  • 지도 좌표와 출구 번호, “오시는 길” 문구 확인 — 재생 버튼으로 동선 확인
  • index.html 맨 위 카톡 미리보기 3줄 교체
  • “최고·최상·초역세권·급매”처럼 과장 광고로 보일 수 있는 표현 점검
  • 휴대폰으로 열어 전화 버튼이 내 번호로 걸리는지 확인

12자주 묻는 질문

화면 맨 위에 빨간 “설정 오류” 줄이 떠요

안내된 파일·줄 번호 근처에서 따옴표나 쉼표가 빠졌습니다. 바로 위 줄 끝에 쉼표가 있는지, 따옴표가 짝이 맞는지 확인하세요.

고쳤는데 화면이 안 바뀌어요

저장했는지 확인하고 Ctrl + Shift + R(맥은 Cmd + Shift + R)로 강력 새로고침합니다. 사진은 파일 이름(대소문자, .jpg/.png)이 정확히 같아야 합니다.

“실제 지도” 탭이 비어 있어요

내 컴퓨터에서 파일로 열면 지도가 안 나올 때가 있습니다. 인터넷에 올린 뒤에는 정상적으로 보입니다. 아래 네이버·카카오·구글 지도 버튼은 항상 동작합니다.

지도에서 건물 위치가 조금 어긋나요

office.at을 건물 한가운데로, exits를 출구 계단 위치로 다시 찍어 보세요. 건물 크기는 office.size(m)로 조절합니다.

예시로 들어 있는 상호·연락처·대표 이력·매물 정보는 미스터홈즈 서초 부동산의 것입니다. 내 홈페이지로 올리기 전 반드시 모두 바꿔 주세요. 예시 사진은 Unsplash 라이선스, 글꼴은 Pretendard·IBM Plex Sans KR(SIL Open Font License)입니다.
