빌드 도구 없이 HTML·CSS·JS만으로 동작하므로 폴더를 그대로 올리면 됩니다.

## 매물 바꾸기

`js/listings.js` 한 파일만 고치면 됩니다.

1. `FEATURED` — 맨 위 대표 매물 2개. `legal` 항목이 "상세 · 법정 표시사항" 창에 그대로 나옵니다.
2. `CASES` — 유형별 사례 6개.
3. 실제 매물로 바꾼 뒤 `SAMPLE_MODE: false` 로 바꾸면 카드의 "예시" 표시가 사라집니다.
4. 계약이 끝난 매물은 `status: "계약완료"` 로 바꾸면 화면에서 바로 빠집니다.

> 인터넷 매물 광고에는 소재지·면적(㎡)·가격·종류·거래 형태·총 층수·사용승인일·방향·방/욕실 수·입주가능일·주차대수·관리비를 모두 적어야 합니다(공인중개사법 시행령 제17조의2). 해당 없는 항목은 "해당 없음"으로 적어 주세요.
