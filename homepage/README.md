# 미스터홈즈 서초 부동산 홈페이지

강남구 삼성동 선정릉역 3번 출구 앞 **미스터홈즈 부동산중개**의 한 페이지짜리 홈페이지입니다.
빌드 도구 없이 HTML·CSS·JS만으로 동작하므로 폴더를 그대로 올리면 됩니다.

## 화면 구성

| 순서 | 구역 | 내용 |
|---|---|---|
| 1 | 히어로 | 대표 이미지 + "삼성동의 최상위 매물 보유한 신뢰와 실력으로 전문중개합니다." + 대표 매물 2개 |
| 2 | 이력 요약 | 공법 강의 28년 · 도시계획 박사 · 체인 100+ · 부동산AI학과 교수 |
| 3 | 유형별 사례 | 빌딩·사옥·토지·상가·주택·컨설팅 6장. 자동으로 흐르고, 마우스를 올린 쪽으로 움직이며 올린 카드가 떠오름 |
| 4 | 전문성 | 대표 소개, 공법 검토·매각·법률 세무 연계 |
| 5 | 거래 순서 | 상담 → 분석 → 현장 브리핑 → 계약·사후관리 |
| 6 | 오시는 길 | 실측 비율 지도 + **재생 버튼을 누르면** 열차 도착 → 3번 출구 → 약 20m 도보 → 2층 202호 순서로 움직이는 길 안내. 네이버·카카오·구글 지도 바로가기 |
| 7 | 상담 신청 | 매입·매도·임대·컨설팅 문의서 |
| 8 | 푸터 | 공인중개사법 제18조의2 법정 표시사항 (명칭·소재지·연락처·등록번호·개업공인중개사) |

모바일에서는 화면 아래에 **전화 · 상담 신청 · 오시는 길** 버튼이 고정됩니다.

## 고치는 곳

| 파일 | 내용 |
|---|---|
| `js/config.js` | 사무소 정보(법정 표시사항), 맨 위 문구, 이력, 대표 소개, 거래 순서, 오시는 길 문구, **지도 좌표** |
| `js/listings.js` | 대표 매물 2개, 유형별 사례 6개 |
| `images/` | 사진 (같은 이름으로 덮어쓰기, `ceo.jpg`를 넣으면 대표 사진 자동 표시) |
| `index.html` 맨 위 | 카카오톡 공유 미리보기 문구(og 3줄) |

- 지도는 `config.js`의 `map` 좌표(사거리 중심·큰길 방향·출구·사무소·걷는 길)로 자동으로 그려집니다.
- 설정 파일에 오타가 있으면 화면 맨 위에 빨간 줄로 파일·줄 번호를 알려 줍니다.
- 실제 매물로 바꾼 뒤 `SAMPLE_MODE: false`, 계약된 매물은 `status: "계약완료"`.
- 상담 신청서는 `formEndpoint`에 Formspree 주소를 넣으면 이메일로 받습니다.
