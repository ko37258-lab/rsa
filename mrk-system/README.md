# MR.K 관리 시스템

코리빙·단기임대 지점을 위한 임대관리(PMS) 웹앱입니다.
홈즈 PMS(`pms-kr.stag.homes.global`)를 역공학(REA)해 같은 업무 흐름과 같은 API 경로로 다시 만들고, MR.K 브랜드와 새 기능을 더했습니다.

- 분석 보고서: [docs/REA.md](docs/REA.md)
- 기본은 **브라우저 안 Mock API**로 동작합니다. 서버 없이 `npm run dev` 만으로 3개 지점·96개 호실의 시연 데이터가 오늘 날짜 기준으로 만들어집니다.

## 실행

```bash
cd mrk-system
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ 에 정적 파일 — 아무 정적 호스팅(Vercel, Netlify, S3)에 올리면 된다
```

- **실제로 쓰기**: 왼쪽 메뉴 **설정 → 빈 상태로 시작**에서 회사·지점·계약 조건·룸타입·호실 번호(예: 101-105, 201-205)를 넣으면 바로 운영할 수 있습니다.
- 데이터는 그 브라우저(IndexedDB)에 저장됩니다. **설정 → 백업**으로 파일을 내려받아 두고, 다른 PC에서는 불러오기로 옮깁니다.
- **설정 → 시연 데이터 다시 만들기**로 언제든 시연 상태로 돌릴 수 있습니다(실사용 데이터가 있으면 먼저 백업).
- 원본 PMS 기능 대조표는 [docs/REA.md](docs/REA.md) 8절에 있습니다.

## 실제 서버에 붙이기

`.env.example` 을 `.env` 로 복사하고 `VITE_API_BASE` 에 서버 주소를 넣으면 Mock 대신 실제 `/api/*` 를 부릅니다(쿠키 인증, 401이면 `/api/auth/login` 으로 이동).
경로는 원본 홈즈 PMS와 같게 맞춰 두었고, 응답 필드는 `src/types.ts` 에 정리했습니다. 필드가 다르면 `src/api/client.ts` 에서 어댑터로 맞춥니다.

## 구조

```
src/
  types.ts            도메인 모델(원본 응답 필드명 유지)
  api/client.ts       API 클라이언트(Mock ↔ 실서버 전환)
  mock/               Mock API — seed(시연 데이터), logic(공통 계산), handlers/(영역별 경로)
  lib/                포맷터·날짜·코드(상태 라벨)·훅·지점 컨텍스트
  components/ui       버튼·배지·표·대화상자 등 공통 부품
  components/charts   SVG 차트(선·막대·열지도·스파크라인)
  layout/AppShell.tsx 사이드바·상단바(지점 전환, 새로 만들기, 알림, 테마)
  pages/              메뉴별 화면
```

기술: React 18 · TypeScript · Vite · Tailwind CSS · TanStack Query · React Router(해시 라우팅) · date-fns · lucide 아이콘.
