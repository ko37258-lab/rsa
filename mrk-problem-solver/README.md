# mrk-problem-solver (Mr. K 문제 바로 해설) — 수정본

https://mrk-problem-solver.vercel.app 에 배포된 앱의 수정 파일입니다.
로컬 배포 폴더(`문제해설기`)에 아래 파일을 덮어쓰거나 추가한 뒤 `npx vercel --prod --yes`로 배포하세요.

| 파일 | 변경 |
|---|---|
| `app.html` | 해설 결과 아래 **[문제로 저장]** → 문제 형식(번호·5지선다·정답·해설) 박스, 클릭 시 서식 포함 전체 복사(한글·워드 붙여넣기). 정밀 조회 도구 5종 연결 |
| `api/law-plus.js` | **신규** 정밀 조회 프록시: 조문 키워드 찾기 · 위임조문 3단비교 · 별표 원문 · 법령해석례 검색/원문 |
| `index.html`, `package.json` | 배포본과 동일 (참고용) |

기존 `api/law.js`(법령검색·조문·판례 프록시)는 변경하지 않았으며 이 폴더에는 포함되어 있지 않습니다. 로컬 폴더의 파일을 그대로 사용하세요.
