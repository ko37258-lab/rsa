## MR.K Typeless 데스크톱 (Windows)

어느 창에서든 **Win+H**를 누르고 말하면, 받아쓰고 정리해서 그 자리에 바로 입력합니다.

### 설치
1. 아래 **MRK-Typeless-Setup.exe**를 내려받아 실행합니다. 관리자 권한은 필요 없습니다.
2. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다 (서명하지 않은 프로그램이라 처음 한 번 뜹니다).
3. 설정 창에 **Gemini API 키** 하나를 넣고 저장하면 끝입니다. '키 발급 ↗'을 누르면 Google AI Studio가 열립니다.

설치하지 않고 바로 쓰려면 **MRK-Typeless.exe**(한 파일)를 받아 실행해도 됩니다.

### 쓰는 법
- **Win+H** → 말하기 → **Win+H** 한 번 더: 받아쓰고 정리해서 붙여넣기 (Windows 음성 입력 대신 MR.K가 열림)
- **Ctrl+Shift+Space** 누른 채 말하고 떼기
- **Ctrl+Alt+Space** 선택한 글 정리 · **Ctrl+Alt+E** 선택한 글 말로 고치기 · **Esc** 녹음 버리기
- 작업 표시줄 오른쪽 아래 MR.K 아이콘을 누르면 **사용 방법**이 열립니다.

### 1.1.0에서 바뀐 점
- 설치 프로그램(시작 메뉴·바탕화면 바로가기, 자동 실행, 제거) 추가
- Win+H로 MR.K 받아쓰기 (설정에서 끌 수 있음)
- Gemini API 키 하나로 받아쓰기와 정리를 모두 (Claude·ElevenLabs 키도 그대로 쓸 수 있음)
- 사용 방법 창: 트레이 아이콘을 누르거나 처음 설정을 마치면 열림
- 설정 창을 탭으로 나눔 (시작하기 · 받아쓰기·정리 · 글 · 단축키·기타)
